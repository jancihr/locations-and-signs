SIGNS AND LOCATIONS

by Zorka and Janči

This is an interactive map of world writing systems (signs). You can trigger animations to reveal layers of typography for different scripts. For fun, signs spread around the world from their home origin or randomly as you choose. You can turn on the sound to hear harmonic tones as signs expand or shrink. You can even listen to Ode to Joy, while signs perform a show. The map is based on the scripts' historical and modern origins, but the animations are purely artistic and not meant to be historically accurate.

Interaction

  • Clicking on a map region: Starts the expansion animation for that region from the click point. In case of the random button in the menu selected, a random signs will start expanding from a random position within the map boundaries.

Menu Buttons

  • MENU: Shows or hides more control buttons.
  • INFO: Shows or hides this description.
  • AUTORUN: Toggles automatic playback, where regions are randomly activated. When animations are running, this button freezes/unfreezes them.
  • JOY: Play Ode to Joy, No 9. by Beethoven. The pitch changes as regions expand and contract.
  • SOUND: Toggles sound on/off. The pitch changes as a region expands or contracts.
  • CLEAR: Resets the map to its empty state, clearing all animations and audio.
  • REPLANT: Regenerates all script images.
  • PAUSE: Pauses/resumes all running animations and audio.
  • COLOUR: Selects the color palette for the scripts.
    • COLOUR: Uses a curated set of cheerful colors for each region.
    • RANDOM: Each script gets a new random, vibrant color when images are generated.
    • INK: All scripts are rendered in shades of blue.
  • ORIGIN MODE: Selects the starting point for animations triggered from the menu.
    • HOME: Animations start from their script's historical/geographical origin point.
    • ANYWHERE: Animations start from a random point within the visible map area.
    • CENTER: All animations start from the center of the visible map.
  • FONT FAMILY: Selects the font family (Sans Serif, Serif, Monospace, Cursive, Fantasy) used to generate the script images.
  • SPEED: Adjusts the animation speed. Drag right for normal speed (1.0x), left for slower.
  • FONT SIZE: Adjusts the base font size used to generate the script images. Images are regenerated when you release the slider.
  • BORDERS: Toggles a layer showing the boundaries of the script regions.
  • REGIONS: Toggles a colored overlay for each script region.
  • Region Buttons: Starts or stops or reverses the animation for specific signs.

Keyboard Shortcuts

  • M: Toggle MENU
  • I: Toggle INFO
  • A: Toggle AUTORUN
  • J: Play ODE FOR JOY.
  • S: Toggle SOUND
  • L: Cycle through COLOUR modes (Random, Predefined, Blue)
  • R: Cycle through ORIGIN modes (Predefined, Random, Center)
  • F: Cycle FONT FAMILY
  • B: Toggle BORDERS
  • G: Toggle REGIONS
  • C: CLEAR
  • E: REPLANT
  • SPACE: PAUSE/RESUME
  • 1..9,0,O,P : Start/stop regions
